## Featured project

### Cross-lingual multimodal sentiment analysis

**Team project · Chinese + English · video → sentiment**

A video-to-sentiment pipeline that combines speech, text, and visual signals, then fuses them with cross-attention. The project includes training and evaluation workflows, visualization, and bilingual documentation. I worked on this codebase with the team and maintain a [public working repository](https://github.com/MaYangle/Multimodal-Sentiment-Analysis).

`Python` &nbsp; `PyTorch` &nbsp; `Whisper` &nbsp; `BERT` &nbsp; `Cross-attention`
